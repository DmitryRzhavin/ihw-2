# Тестовые сценарии

Основная команда:

```bash
./scripts/run_tests.sh
```

Проверяются:

- стандартный сценарий;
- ограниченная кухонная очередь;
- отмена невыполнимого заказа;
- ограниченная зона готовых блюд;
- режим LIFO;
- воспроизводимость автоматически формируемых заказов по `seed`;
- корректное завершение по `SIGINT` с кодом 130;
- встроенные тесты CTest.

Дополнительно можно запустить проверки санитайзерами:

```bash
./scripts/run_sanitizers.sh
```

Вторая команда требует, чтобы установленный GCC поддерживал AddressSanitizer,
UndefinedBehaviorSanitizer и ThreadSanitizer.
